# Sumi brand artwork

The viewer is called **Sumi for Supernote** ("Sumi" on iOS). Sumi (墨) is the ink of Japanese calligraphy and ink painting. The app keeps handwriting exactly as it was written, in crisp vector ink, and makes it searchable.

`sheet.png` shows every logo option at App Store, home-screen and Settings sizes. `svg/` holds the 1024×1024 full-bleed sources; iOS and macOS apply the rounded mask.

The app icon uses **Brush S on washi** (`svg/sumi-brush-washi.svg`). Its layers are generated by `Artwork/artwork.py` (`brush_s()`, `washi_texture()`) and `Artwork/render.sh`.

## Logos

| File prefix | Idea |
|---|---|
| `sumi-today-*` | The original pen S, unchanged |
| `sumi-brush-*` | The S painted with a brush (app icon) |
| `sumi-seal-*` | Brush S signed with an indigo seal reading 墨 ("ink"). Have a Japanese reader check the seal before using it. |
| `sumi-enso-*` | Ensō brush circle with the indigo dot |
| `sumi-ensos-*` | The S inside an ensō |
| `sumi-drop-*` | A drop of sumi with the S reversed out |
| `sumi-word-*` | The S with a small "sumi" wordmark (avoid at small sizes) |

Colourways: `washi` (paper), `ink` (sumi black), `navy` (indigo), `paper` (ruled paper).

## Palette

| Name | Hex | Use |
|---|---|---|
| Sumi | `#151515` | Ink, text |
| Usuzumi ("thin ink") | `#8A8780` | Secondary text, rules |
| Washi | `#EDE9DF` | Paper, icon background |
| Ai-iro (indigo) | `#2B4C8C` | The full stop, accents |
| Ai, light | `#5D86D6` | Accent on dark backgrounds |

## Type and voice

- Wordmark: "Sumi." in a Didone serif (Didot), or "sumi." in a light lowercase sans. Keep the indigo full stop.
- Taglines: "Your notes, in ink." · "Ink that travels." · "Every stroke, everywhere."
- App Store: name "Sumi for Supernote", subtitle "View & search your handwriting".

## Re-rendering

The brush and paper textures are SVG filters, so the PNGs are rendered with headless Chrome:

```sh
Artwork/concepts/render.sh sumi-   # PNGs in Artwork/concepts/build/png/
Artwork/concepts/render.sh         # all concepts (also Remora and Quire) plus contact sheets
```

`Artwork/concepts/concepts.py` draws every logo. Copy new SVGs from `Artwork/concepts/build/svg/` into `svg/` here.
